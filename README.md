# 💬 Comment Category Prediction using Machine Learning & NLP

A Machine Learning and Natural Language Processing (NLP) project focused on predicting comment categories using textual and structured features.  
The project includes exploratory data analysis (EDA), preprocessing, feature engineering, text vectorization using TF-IDF, and training multiple machine learning models for classification.

---

# 🚀 Project Overview

User-generated comments often contain valuable insights and patterns.  
This project aims to classify comments into different categories using:
- NLP techniques
- Structured data preprocessing
- Machine learning classification models

The complete workflow was implemented and experimented on the Kaggle platform.
